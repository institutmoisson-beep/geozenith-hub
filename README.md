# Fleet Compass

Créer une plateforme SaaS de tracking GPS moderne.

Fonctionnalités :

- Authentification

- Multi-utilisateurs

- Gestion de flotte

- Carte OpenStreetMap

- API Traccar

- Historique trajets

- Géofencing

- Alertes

- Rapports PDF

- Dashboard statistiques

- Facturation

- Abonnements

- Notifications WhatsApp

- Application mobile PWA

Technologies :

Frontend :

- React

- Tailwind

Backend :

- Supabase

GPS :

- Traccar API

Cartographie :

- OpenStreetMap

- Leaflet

IA :

- Llama 3 via Ollama

Créer une interface moderne similaire aux meilleures plateformes GPS mondiales. Avec une page d'accueil , couleur orange et rose qui surrse kaki premium. Une appli premium avec pour nom MSN Tracker .
